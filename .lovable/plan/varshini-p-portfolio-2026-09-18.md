# Varshini P Portfolio

## Scope
- Build a polished, single-page personal portfolio at `/` using the supplied navy, blue, white, and light-grey visual system.
- Include sticky navigation, mobile menu, active-section tracking, smooth scrolling, subtle reveal animations, and a floating back-to-top control.
- Add every supplied section and all exact professional, education, project, certification, language, and contact details.
- Add working email, phone, LinkedIn, and resume-download actions; include the supplied PDF as the downloadable resume.
- Add a validated contact form that clearly opens the visitor's email application rather than claiming a server submission.

## Structure
- Keep portfolio content in structured data and split shared interface pieces into reusable components.
- Use semantic landmarks and headings, one H1, accessible labels, keyboard focus states, and reduced-motion support.
- Create recruiter-focused page metadata and Person JSON-LD using only supplied facts.

## Visual Direction
- Restrained finance aesthetic with Inter typography, navy headers, professional blue actions, soft grey section bands, subtle borders, small-radius cards, and Lucide line icons.
- No stock imagery, gradients, glass effects, charts, counters, progress bars, or fabricated content.

## Verification
- Check desktop and mobile layouts in the browser.
- Test navigation, mobile menu, contact validation, phone/email/LinkedIn links, resume download, active states, and back-to-top behavior.
- Confirm no horizontal overflow, browser errors, or missing content.
